# 概念段落草稿：接在 Matching rules 前面

Recipe comparison considers both local ingredient–action semantics and the position of a sequence within the global recipe context. Because a recipe may contain multiple branches, the same ingredient–action sequence can occur more than once. For example, the same seasoning may undergo repeated processing or be incorporated in the same way into different components of a dish. Local semantic similarity alone is therefore insufficient to establish correspondence. We also consider the branch to which each sequence belongs and its position within that branch, distinguishing similar operations that serve different procedural contexts. Within corresponding branches, states are then compared according to the exact, similar, and different categories defined below.
